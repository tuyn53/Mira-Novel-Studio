# 原型与验收

更新：2026-11-03。原型和页面共用 Vue 源码，不再维护一份易失真的独立 HTML 设计稿。

## 1. 浏览入口

启动 npm run dev 后打开 http://127.0.0.1:5180/。npm run dev:prototype 打开 /prototype/index.html，HTML 标记确保即使放进 iframe 也只展示示例。

| 路由（hash 后） | 验证内容 |
| --- | --- |
| / | 作品列表、搜索、继续浏览、示例标识 |
| /new | 两步开书浏览；创作输入只读，创建关闭 |
| /book/fog-harbor/blueprint | 五项蓝图、近期规划提示、前往正文 |
| /book/fog-harbor/plan | 全书脉络、逐章展开、进入所选章 |
| /book/fog-harbor/write | 章目录、章纲、字号、专注、伴写/上下文 |
| /book/fog-harbor/knowledge | 分类、搜索、设定详情及来源说明 |
| /book/fog-harbor/review | 示例正文/章纲提案、双栏对比、处理按钮关闭 |
| /settings | 接入状态、模型字段与职责边界 |

面向 1280–1600px 桌面工作区，1440px 为主要设计尺寸；本轮不交付移动创作产品。较窄窗口不应默默开启编辑功能。

## 2. 浏览模式验收

- 页面明确显示浏览模式、示例作品；不显示虚假的在线模型或已保存。
- 搜索、选章、分类、展开细纲、上下文预览、字号和专注可用。
- 新建、改稿、添加章节/设定、生成、采纳、定稿、模型配置保存不可用。
- 不写 localStorage、IndexedDB，不向模型供应商发请求。
- 静态构建及 prototype 子目录入口的字体、图标、路由正确。

## 3. 自动化分层

- npm run typecheck：Vue/TypeScript 与构建配置类型。
- npm test：段落对比、提案隔离/基线变化/幂等、记忆失效与上下文预算、端口请求生命周期。
- npm run build：相对路径静态产物和原型双入口。
- npm run test:browser：模拟父窗与 MessageChannel，仅用固定模型结果和内存数据，验证 UI 与草案协议。**这不是当前 Mira 已支持相应 API 的证据。**
- 人工视觉：1440×960 和 1280×800 桌面页面；截图检查长文本、滚动区、审阅底栏和专注交互。

## 4. 真实 Mira 尚待验收

| 验收 | 状态与原因 |
| --- | --- |
| 独立应用登记、授权、安装/卸载 | 未验收；宿主未登记且缺所需能力 |
| 新建→保存→关闭→重开 | 未验收；novel.* 未实现 |
| 真实供应商模型与模型目录 | 未验收；独立文本生成 API 未实现 |
| 提案与正文跨调用保存的一致性 | 模拟可测；宿主需要决定事务/存储契约 |
| 长生成时离开、关闭、崩溃恢复 | 页面会拒绝 prepare-leave；实际桌面行为待验收 |
| 多实例冲突、旧作品迁移 | 未实现，需独立契约和隔离数据验证 |
| macOS/Windows Electron 打包与升级 | 未验收；浏览器检查不能替代 |

本轮不通过修改 Harness 来隐藏接入缺口，不将 SDK 草案、包声明或模拟测试称为生产接入完成。

## 5. 本轮执行记录

2026-11-03：类型检查通过；17 项领域/端口单测通过；生产构建通过。浏览器模拟协议覆盖只读锁定、当前宿主缺能力拒绝、编辑保存、主题事件、生成单次执行、离开拒绝、提案采纳、记忆定稿、部分保存失败/重试及重开。八个桌面路由无页面脚本异常、无整页横向溢出；完成 1440×960、1280×800 与暗色截图复核。真实 Mira 项目仍缺前述 SDK，未启动或调用真实模型。

沙箱适配：关闭可选 Vue Devtools bridge，避免其导入时探测 localStorage 导致 opaque-origin iframe 启动失败；Pinia 状态管理保留。开发静态资源 CORS 仅允许 null origin 和本机回环源，供同等 sandbox 联调。

独立界面复核结论为 ship，范围限于已评分的五项修复：接入状态措辞、审阅首处修改定位、标题层级、辅助文字对比及伴写标签键盘行为。ArrowLeft、ArrowRight、Home、End 的实际浏览器证据确认焦点、aria-selected、roving tabindex 与面板关联一致；此结论不覆盖真实 Mira 模型、存储、安装或后端集成。设计规范从实装提取到 DESIGN.md 与 .impeccable/design.json。

最终使用生产构建（5181 预览服务）重跑模拟宿主浏览器测试，通过。根入口与 /prototype/index.html 均确认两个字体资源返回 200、38 个 SVG 图标正常渲染、正文没有可编辑文本框、生成按钮禁用；无页面脚本错误、资源失败或整页横向溢出。
